# Laptop Price Prediction

A machine learning project that predicts laptop prices based on hardware and specifications.

## Project Overview

This project covers the complete ML workflow:

- Data preprocessing
- Exploratory Data Analysis
- Feature engineering
- Machine Learning model training
- Model evaluation
- FastAPI model deployment
- Streamlit frontend
- Dockerized FastAPI backend

## Model

The trained regression model achieved an R² score of approximately **0.83**.

The trained model is saved as:

`laptop_price_model.pkl`

## Tech Stack

- Python
- NumPy
- Pandas
- Scikit-learn
- FastAPI
- Uvicorn
- Streamlit
- Docker
